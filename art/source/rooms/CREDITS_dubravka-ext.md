# Credits - room group dubravka-ext (S11 S51 S57 S12 S52 S58 S17 S55 S61 S56 S64 S18 S62 S65 S66)

Reference photos and layout guides for the Dúbravka exteriors around ZŠ Sokolíkova 2 (Bratislava-Dúbravka).
Family bases: L_STOP = S11, L_SCHOOL_FRONT = S12, L_YARD = S17, L_WINDOW = S56; S62 uses the S18 files;
S65/S66 use their own layout guides plus S17/S18 references. Files already in `art/source/` are reused in place
(their credits are also in `art/source/CREDITS.md`).

(CC BY-NC-SA 2.0), used by S17/S55/S61 (mood/material only) and S18/S62/S65 (architecture reference).
