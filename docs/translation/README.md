# English translation

confirmation for now, then recheck yourself using some of your language plugins [don't include fal here]".

## Method

1. **Glossary first** – `GLOSSARY_EN.md` / `glossary_en.json`: British English, one rendering per term, names and
   places, forms of address, the bell pun, protected facts, humour rules.
2. **Translation** – Claude, scene by scene in play order with the context bundles (`context/C1-C4.md`, generated by
   `tools/writing_bundles.py`), batches in `en/*.json` ({key: english}). `tools/en_batches.py`:
   `prefill` (fixed renderings from the glossary), `autofill` (room names on exit labels, identical sentences),
   `dump <chunk>` (next untranslated keys with context), `check` (placeholders, markup, leftover Slovak), `status`,
   `merge` (writes `src/game/localization/overrides/en.csv` and the en column of `ui.csv`).
3. **Local check** – `tools/en_languagetool.py`: LanguageTool en-GB on this computer (Java + language_tool_python),
   report `languagetool.json`; real findings fixed in `en/C5_languagetool_fixes.json`, the rest are names, British
   commas or glossary terms ("the write").
4. **Standard/Hard variants** – `en/C6_guidance_std.json` (the `<key>.std` texts of
   `src/game/localization/overrides/guidance_std.csv`).

## In the game

- `tools/extract_strings.py` puts `overrides/en.csv` into the en column of `dialogue.csv` and `world.csv`;
  `en_batches.py merge` fills `ui.csv` (hand-written). `tools/check_strings.py` checks placeholders in both languages.
- Settings → Jazyk / Language. A first start follows the system language (Slovak or Czech → Slovak, else English);
  QA runs start in Slovak, `--locale en` switches a QA run.
- Voices stay Slovak with English subtitles. The window title follows the language (*The Last Bell*).
- Painted text in the backgrounds stays Slovak (real signage); every text a player needs is also in a look or line.

## Review page

`tools/en_review_page.py` → `review.html`: every text in Slovak and English side by side, in play order, with search
and filters; the Standard/Hard versions are shown under their base text.

## Adding a language

Add a column to the tables (`text_keys.HEADER`), a source file like `overrides/en.csv`, the `.translation` files to
`project.godot` (`locale/translations`) and a choice in `SettingsScreen.cs`.
