# Handoff issues found during implementation

| id | file | description | resolution |
|---|---|---|---|
| CORE-01 | validate_handoff.py | Running the validator in place rewrites `walkthrough.json` and `validation_report.json`, which ARCHITECTURE.md declares read-only. | Run it only on a copy (`python validate_handoff.py <copy>/game.json`). LastBell.Core.Tests re-implements its checks (walkthrough replay, postgame, 120 random orders, 24 port orders, save round-trips) without touching the files. |
| CORE-02 | acceptance_tests.csv (AT16) | Says "all seven cutscenes"; game.json has nine (CS01–CS09; CS08 for E10 and CS09 for J02 came with revision 2.0). | Test AT16 covers all nine. Proposed fix: change the CSV text to "deväť". |
| CORE-03 | ARCHITECTURE.md key table | `quest.<id>.reward` and `era.<year>.card` have no source text in game.json (quests have no reward field, eras only a date). | Core exposes the keys with fallbacks: reward = "" (the side quest reward is the album/epilogue entry), card = ISO date. Proposed fix: author the texts in `world.csv` or drop the keys. |
| CORE-04 | runtime_contract.ts `itemActionLabel` | Returns the action label for any action resolution, also for a default click without a selected item; the bible only specifies the item case (label only for an executable rule, otherwise empty). | Ported verbatim. `ViewBuilder.Hover` returns `Name` and `ActionLabel` separately, so the presentation can show the hotspot name without item; with a selected item the label is non-empty only for an executable rule (tested). |
| CORE-05 | runtime_contract.ts `commitAction` | Does not check `selected_item`; only the resolver matches the cursor item. | Ported verbatim (the resolver is the only UI path to a commit). Noted for anyone calling `CommitAction` directly. |
| CORE-06 | PRIBEH_A_PRAVIDLA.txt (inventory) | "Unneeded documents are archived" but items carry no document flag (all `disposition: retain`). | `ViewBuilder.IsArchived`: an owned item with no remaining possible use is archived (view only, still owned); CHRONO never. |
| CORE-07 | PRIBEH_A_PRAVIDLA.txt vs visual_variant_layers | "Changes take effect after the action and the next entry into the affected scene", but S61 layers (E08 closed niche, E09 tree guard) are triggered inside S61 itself. | Core applies the rule uniformly: `VariantLayerState.DeferredUntilReentry` / `ActiveCausalEffect.DeferredUntilReentry` are true until the room is re-entered; the presentation may animate a local, in-room change instead. Hotspot visibility is never deferred (validator semantics). |
| ART-DUBEXT-01 | game.json rooms S57 (art_brief, ambience), location_families L_STOP 1982 | S57 shows a red-cream tram at the Dúbravka stop in early December 1982, but the tram line reached Dúbravka only in 1984 (to Hanulova) and 1986 (to Pri kríži) (de.wikipedia "Straßenbahn Bratislava"); the real base, the Švantnerova stop, did not exist in 1982. Story logic is unaffected (S57 is a travel node). | Open - needs a product-owner decision. Options: (a) keep the tram as acknowledged fiction; (b) paint the same camera as the tram line under construction (track bed, poles) with a bus at a temporary stop and change the S57 ambience to bus sounds; (c) keep a tram but say nothing about the line. Art for S57 is on hold for the vehicle only; geography/camera are fixed (register design-doc/locations/dubravka-ext.csv). |
| TEXT-01 | game.json quests[].hints[2], puzzles P01/P03/P05 clue | Player-visible hint/clue texts contain internal ids (e.g. "G01 brašna → G02 Ela", "S10.panel:", "CACHEMAP1982"), which the bible forbids. | Kept verbatim in localization tables (game.json is canonical); rewrite the Slovak text in world.csv before release. |
| TEXT-02 | game.json rooms[].district / map | The map shows region names but only the internal `district` field carries them. | Add `region.<district>.name` keys to ui/world tables when the map UI is built. |
| TEXT-03 | game.json cutscenes[].beats[].shot | Shots are stage directions (unkeyed) but contain on-screen text (era card, "KONIEC PRÍBEHU", cable-car sign). | Era card → `era.<year>.*`, end card → `ui.cutscene.the_end`; signs are painted into the art. |
| TEXT-04 | game.json epilogue[].line, puzzles wrong/success lines | 19 texts are stored as "SPEAKER: text". | Tables hold the text only; Core TextKeys must split known speaker prefixes the same way. |
